# 洗車機スタンドマップ

洗車場の位置や基本情報を地図で確認するためのWebアプリです。

## 利用方法

公開ページ: <https://ska0151.github.io/senshaki-map/>

- **現在地に移動**: ブラウザーの位置情報許可後、地図を現在地へ移動します。
- **データ更新**: 掲載地点を再読み込みします。
- **Googleマップで案内**: 選択した地点を目的地としてGoogleマップを開きます。

## 掲載情報について

営業時間、対応する車両、各種寸法・制限などは参考情報です。利用前に現地で最新情報をご確認ください。掲載情報の出所や正確性について疑問がある場合は、プロジェクト管理者へお知らせください。

## 地図の帰属表示

地図データ © [OpenStreetMap contributors](https://www.openstreetmap.org/copyright)。タイルサービスはベストエフォートで提供されます。利用にあたっては[タイル利用ポリシー](https://operations.osmfoundation.org/policies/tiles/)をご確認ください。

地図表示には[Leaflet](https://leafletjs.com/)を使用しています。
